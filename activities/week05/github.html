Git and GitHub Setup

Overview

  • Task: Setup a way to see your web pages on the Internet
  • Purpose: Take a beginning look at versioning control used in the industry.
  • Expectation: Create a repository (folder) that holds all your work in this class.

Instructions

  1. Follow along with your instructor in class to do the following:

    • Create a GitHub account

    • Use your wdd130 folder as a repository

    • Install and open GitHub desktop to manage your repository

    • Setup GitHub Pages

  2. Submit

    The URL(web address) of either your white water rafting or home/portal page.

    • Do Not submit a Live Server URL

    • Do Not submit a GitHub repository URL

    • Your link should look like:

    • yourusername.github.io/wdd130/wwr/index.html
